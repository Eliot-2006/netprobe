NetProbe sample reports

NetProbe is an offline PCAP analyzer written in C++20. These reports were generated by netprobe analyze <capture> --html report.html --deterministic from the synthetic captures in the repository's samples/ folder. Each report is one self-contained file with no scripts or external requests.

TCP lossy_bulk_transfer.pcap 6 bulk TCP transfers with capture loss and reordering: incomplete streams drawn to scale, exact missing byte ranges. MIX mixed_traffic.pcap 40 flows: TCP and UDP, IPv4 and IPv6, VLAN tags, retransmissions and a malformed frame. TCP http_session.pcap One clean HTTP-style session: the all-clear case.
Source, design notes and benchmarks: github.com/Eliot-2006/netprobe
